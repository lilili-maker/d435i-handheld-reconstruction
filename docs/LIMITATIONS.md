# 误差、已知问题与适用边界

本项目用于离线算法实验和大致形状观察，**有一定误差，长序列中也可能出现严重变形**。没有真实轨迹和独立测量基准，不提供固定毫米误差、百分比准确率或制造级精度承诺。

## 误差来源

| 来源 | 可能表现 | 建议 |
| --- | --- | --- |
| 金属、反光、黑色、薄腿与网面 | 缺失或错误深度，腿/轮子断裂 | 先看原始Depth；换观察角度，避免强反光，保留RGB作为对照 |
| RGB低纹理、重复纹理、运动模糊 | 估计失败或错误局部配准 | 慢移、稳定光照，保持明显纹理和高重叠 |
| 曝光变化、RGB/Depth时间差或实际对齐问题 | 灰度不一致、边缘重影 | 对比原始RGB/Depth和实际内参，不只检查尺寸 |
| 链式轨迹累计漂移 | 整体拉长、双层表面、远端错位 | 先短序列，同数据比较后端，检查真实重复观测 |
| 错误回环或退化几何 | 全局优化后形状扭曲 | 只接受独立几何与特征验证的约束；没有回环时明确局限 |
| 移动家具或椅座相对底座旋转 | 静态场景假设不成立，结构分裂 | 整件家具保持静止，相机移动 |
| 背景参与融合 | 实验室场景或地面噪声 | 本次坐标系中人工确认裁剪框，不猜测目标位置 |

## 这些指标不能等同于精度

- `min-consistency=0.4`是支持比例门槛，不是40%正确率，也不是40%误差。
- ICP fitness、inlier RMSE、正反向一致性和深度支持是配准诊断，不是真实相机位姿误差。
- 图像输入质量通过不证明整段轨迹可靠。
- Pose Graph优化成功、顶点增多、表面积增大或Mesh能回读不证明模型更准确或更完整。
- 合成测试有已知几何，只验证数学/软件行为，不验证D435i实际测量精度。

## 严重异常时

1. 保留原图和本次报告，不通过平滑、补洞、删除碎片掩盖问题。
2. 读取registration_quality.json，定位第一对失败/低质量帧，检查实际有效帧与融合帧。
3. 检查相机轨迹范围、单步运动、相对方向、深度尺度及TSDF外参。
4. 用同一短区间比较Legacy与Tensor；不能只把看起来较好的结果当作算法正确证明。
5. 后续片段可以独立重建，但没有可靠相对变换时不能直接拼接。
6. 原始深度大面积缺失、物体移动或视角覆盖不足时，应重新拍摄。

不补造未拍到的轮子、底座或背面。不把模拟位姿或Odometry输出描述为真实机器人测量。
