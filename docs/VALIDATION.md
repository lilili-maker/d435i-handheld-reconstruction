# 验证范围与合成结果

## 离线测试

项目包含130项离线测试，覆盖真实Legacy/Tensor调用、非交换旋转和平移、相机位姿读写、Pose Graph、已知平面TSDF融合、失败停止、受限恢复、RGB颜色、Mesh有效性和防覆盖。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

[GitHub Actions](https://github.com/lilili-maker/d435i-handheld-reconstruction/actions)在Windows / Python 3.14环境安装依赖，运行全部测试和三帧合成数据的完整重建。2026-10-16的工作流已通过；后续提交以Actions中对应提交的状态为准。

## 合成数据的完整重建

scripts/create_synthetic_demo.py使用已知三面角和相机位姿，通过射线求交生成RGB-D。输入明确标记simulation，已知位姿单独保存。手持入口从图像重新计算Odometry，不直接使用真值作为估计结果。

点数与面数可能随平台或依赖版本略有变化。这些是三面角软件演示结果，不是家具模型指标或实际扫描精度。

## 验证边界

真实家具重建的精度尚无独立标定。实际手持扫描可能出现漂移、拉伸、重影、孔洞和背景噪声。单元测试、合成重建和Mesh回读均不能证明真实模型准确或完整。

代码不补造未扫描几何，不把失败帧伪装成成功，不用几何后处理掩盖轨迹问题。Windows长路径与8.3短路径按同一实际文件检查，避免路径拼写差异造成误报。
