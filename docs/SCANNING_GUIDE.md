# 手持环绕拍摄指南

1. 固定家具的所有活动部分，尤其旋转椅上半部与底座。保持背景静止。
2. 清理周围通道，避免拍摄时被遮挡；让整体结构尽量进入画面，不只拍椅背和坐垫。
3. 保持稳定柔和光照，避免直接对窗户、强灯或反光金属高光拍摄。先观察RGB和Depth预览。
4. 缓慢平移并渐进改变角度，相邻视角保留较大重叠；避免突然转向、快速上下移动和运动模糊。
5. 先录短段并完成重建检查，再扩大扫描。更多帧不一定更好，失跟踪后的帧不会凭空获得可靠位姿。
6. 需要更多高度视角时，在重叠区域平缓过渡。拍到底座/轮子，但不要让相机超出设备的有效测距条件。
7. 结束前缓慢回到与起点相近的真实视角，为可能的回环提供重复观测。回到起点不保证算法能检测到可靠回环。
8. 拍完先看输入报告和若干原始RGB-D，再选稳定参考帧。参考帧不是越早越好，当前程序不自动选最优参考帧。

反光金属、黑色网面和很细的杆件可能一直难以获得稳定深度。不要仅通过降低质量门槛来增加通过帧数。模型尺寸检查需要与实物实测对照，而非只凭视觉判断。

当前项目示例使用的深度过滤通常为0.2～3米；这是软件过滤范围，不保证整个范围内每种材质都有可靠数据。实际可用距离需根据本次Depth预览、设备和拍摄条件判断。
